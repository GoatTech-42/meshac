## Findings
- R1 (delta-explicit, main v36 red-team result): v36 polished the legit path (mouse-step-quantized aim, crosshair-verified clicks, eased walking cap, paced swaps) but the DEFAULT human mode (legit=0) still places up to once per tick with no walking cap: sustained default-mode bridging at full walk predicts CAUGHT by BOTH the 16/s rate check and the 4.0 bps bridging line. Legit mode passes those two by construction; default human can still pass when its real cadence stays under both bars (aim stalls, target gaps). Human mode CAN still pass both when its real cadence stays under the bars (aim stalls and target gaps eat ticks) - so "only legit mode passes" is too strong; the accurate statement is: legit passes by construction, default human passes only when its cadence cooperates. If the rig needs a reliably-passing default-mode row, that is a meadow-side design gap, honestly reported - not a meshac bug.
- R2 (defense-side, unchanged): no meshac check binds rotation snaps at placement. v36's legit aim is now quantized to whole mouse steps (gcdStep from the client sensitivity), making the cover strictly better; the ROTATION-SNAP-AT-PLACE proposal (unpinned) is the only meshac lever. Gap stands as previously priced.
- R3: ScaffoldSwap's paced swap + selection-watch + idle-restore is internally clean (ownership bound, best-effort restore, never over the player). The precise meshac statement: the swapAt check (Interact.use) does not bind block placement. Slot changes/restores are held-item packets and SafeWalk gates movement - both ARE server-visible in general; they merely have no meshac check today.
- R4: findBlock prefers the held slot, then biggest full-cube stack; sand excluded unless sand=1. Placement support scan requires a non-replaceable block with a non-empty collision shape adjacent - a CLIENT-SNAPSHOT claim only: under desync the server can disagree, so airplace=0 makes placed-against-air unlikely by construction, not impossible (the only deliberate airclick remains the airplace=1 positive control).
